# Multi-Tier Inventory & Stock Management System

A production-ready full-stack platform built to handle real-time stock control, automated inventory counting, and multi-tier supply tracking. This architecture directly reflects the database management principles and practical enterprise solutions I engineered during my 4-month industry software engineering internship.

## 🚀 Key Features

- **Real-Time Stock Reconciliation:** Live calculations of inventory inflows and outflows with automated threshold monitors for low-stock indicators.
- **Relational Data Integrity:** Engineered robust database structures managing explicit dependencies between product SKUs, storage locations, and category logs.
- **Transactional Audit Trailing:** Full logging protocols tracking entry adjustments, administrative edits, and stock distribution records.
- **Performance-Optimized UI:** Designed an interactive, scannable administrative dashboard utilizing state synchronization to safely manage rapid data inputs.

## 🛠️ Technical Architecture

- **Frontend Interface:** React.js, Tailwind CSS, Vite
- **Backend Architecture:** Node.js, Express.js RESTful API endpoints
- **Database Layer:** MongoDB (MERN Stack) / PostgreSQL (PERN Stack)  
  
- **State Optimization:** Axios client management with structural error handling for data requests.

## 📈 Engineering Scope

This system was designed to replicate the strict logistics required by distribution environments. The primary engineering goal was maintaining perfect transactional accuracy across multi-layered tables and eliminating state drift during continuous data writes.
